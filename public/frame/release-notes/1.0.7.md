# Frame 1.0.7

This update adds episode monitoring and scheduled search for missing series episodes, alongside library and playback improvements.

- Choose which series, seasons, and episodes to monitor. Review wanted and future episodes, then search Prowlarr for matching releases and add them to Downloads manually or on a schedule.
- Manage series with sortable, configurable list columns, more filters, bulk monitoring controls, and clearer library status and storage details.
- Configure MetalFX upscaling and view playback statistics, including codec, frame rate, dropped frames, and audio/video sync.
- Save the OpenSubtitles password securely in macOS Keychain.

The app is Apple Development signed and is not notarized. macOS may require manual first-launch approval.
