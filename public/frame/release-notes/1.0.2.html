Frame 1.0.2

This update fixes startup on clean installs and retains the local library improvements from 1.0.1.

  • Fix app launch by including the standard Frameworks directory in the runtime library search paths, so bundled Sparkle loads correctly.
  • Keep the bundled media engine in its dedicated framework directory for playback.
  • Store library records, metadata cache, artwork, and thumbnails in one Frame-specific encrypted catalog file.
  • Improve indexed library lookups and local cache performance.

    • The app is Apple Development signed and not notarized. macOS may require manual first-launch approval.
