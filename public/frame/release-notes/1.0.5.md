# Frame 1.0.5

This update addresses the playback UI stall and protects the local catalog when multiple Frame instances are open.

- Keep AppKit responsive while libmpv renders video by disabling its target-time wait on the UI render path.
- Apply the same non-blocking render timing to native Picture in Picture.
- Serialize catalog reads and writes across Frame processes, reload a newer committed catalog generation before access, and reopen the database after atomic compaction replaces it.

The app is Apple Development signed and is not notarized. macOS may require manual first-launch approval.
