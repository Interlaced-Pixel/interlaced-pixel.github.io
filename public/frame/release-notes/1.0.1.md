# Frame 1.0.1

This update upgrades the local library catalog and improves library search and artwork caching.

- Store library records, metadata cache, artwork, and thumbnails in one Frame-specific encrypted catalog file.
- Add indexed title, filename, path, series, and media-kind lookups to speed up library searches.
- Cache query results between library redraws and retain read-only migration support for existing library data.
- Improve database file privacy with owner-only filesystem permissions and transactional recovery.
- Continue to support local movie and series management, bundled media playback, and Sparkle updates.

The app is Apple Development signed and not notarized. macOS may require manual first-launch approval.
