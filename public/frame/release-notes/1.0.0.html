Frame 1.0.0

Initial public release of Frame for macOS.

  • Local movie and television library management with poster and list views.
  • Native playback with broad bundled codec support, full screen, and Picture in Picture.
  • Series episode browsing, metadata refresh, calendar, search, download monitoring, and import tools.
  • Sparkle updates verified with Frame's EdDSA release key.
  • The app is Apple Development signed and not notarized. macOS may require manual first-launch approval.
