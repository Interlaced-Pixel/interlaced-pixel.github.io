Frame 1.0.4

This update fixes restored playback starting automatically after the player restored track preferences.

  • Keep restored videos paused until the media engine confirms the file has loaded, even while audio and subtitle tracks are being selected.
  • Avoid repeated window chrome changes during SwiftUI updates to prevent recursive layout work.
  • Use a native macOS menu-bar status item with options for opening Frame, navigating, refreshing the current library, and close-to-menu-bar behavior.
  • Keep movie runtime and resolution metadata available from library scanning, and simplify movie poster actions when a local file is present.

    • The app is Apple Development signed and not notarized. macOS may require manual first-launch approval.
