# Frame 1.0.3

This update fixes a startup playback issue that could make Frame appear unresponsive when restoring the last video.

- Resume the previously open video in a paused state, even when the playback engine resets pause while loading the file.
- Avoid repeated window chrome changes during SwiftUI updates to prevent recursive layout work.
- Replace the SwiftUI menu-bar scene with a native macOS status item and menu for opening Frame, navigating, refreshing the current library, and configuring close-to-menu-bar behavior.
- Keep movie runtime and resolution metadata available from library scanning, and simplify movie poster actions when a local file is present.

The app is Apple Development signed and not notarized. macOS may require manual first-launch approval.
