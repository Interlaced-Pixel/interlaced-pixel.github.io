# Frame 1.0.10

## Torrent controls and dual-stack networking

- Global download and upload limits now apply across active torrents.
- File priorities affect piece selection and are saved with session state.
- Force recheck now verifies every stored piece, clears corrupt or missing pieces, and preserves paused transfers.
- The peer listener accepts IPv4 and IPv6 connections unless IPv4-only is selected.
- DHT can exchange IPv4 and IPv6 compact peers and nodes over its dual-stack socket.
- The torrent preferences no longer present uTP and automatic router port mapping as available features.

The focused torrent suite completed 50 tests with zero failures; two opt-in live interop cases were skipped in that suite. Separate controlled Transmission 4.1.4 tests for a v1 magnet and `.torrent` completed with SHA-256 matches against the source after the Frame 1.0.10 peer ID and extension identity were updated.

uTP transport, automatic UPnP/NAT-PMP mapping, and BEP 52 piece-layer retrieval for v2 magnets remain unsupported. V2 `.torrent` downloads and v1 magnets were verified. The self-signed local app requires macOS first-launch approval; it is not Apple notarized.
